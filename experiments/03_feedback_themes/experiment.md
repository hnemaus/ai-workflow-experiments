# Customer Feedback → Insight Themes

## Problem

Large surveys produce hundreds of comments that are difficult to analyse manually.

## Solution

Cluster responses into themes using AI.

## Prompt

Analyze the following survey responses.

Return:

Top themes
Frequency estimate
Example quote for each theme

Responses:
{{survey_data}}

## Result

200 responses were grouped into 5 themes within seconds.

## Learnings

AI works best when the prompt explicitly asks for themes + examples.
