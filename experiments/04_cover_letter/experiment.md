# Job Posting → Tailored Cover Letter Draft

## Problem

Writing personalised cover letters takes significant time.

## Solution

Use AI to generate a tailored first draft using the job posting and CV.

## Prompt

Write a tailored cover letter based on the following job posting and CV.

Tone: professional but enthusiastic.

Job posting:
{{job_posting}}

CV:
{{cv}}

## Result

Generated a strong first draft covering relevant experience in under 1 minute.

## Learnings

AI produces best results when both CV and job description are provided.
